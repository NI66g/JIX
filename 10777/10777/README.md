# 🛡️ 電腦周邊智慧退換貨與爭議風控平台
> **資管系畢業專題 · 前後台分離架構 (買家獨立前台 + 商家管理後台)**

---

## 🚀 系統快速啟動說明

本專案採用 **前後台分離** 雙網頁架構，前後台共享同一本地資料庫 (`disputes.db`) 與郵件通知核心，買家無法查看後台審核資訊與商業數據。

### 1. 啟動【買家端獨立門戶】(Customer / Buyer Portal)
開啟終端機（PowerShell 或 CMD），輸入：
```bash
streamlit run buyer.py --server.port 8502
```
- 瀏覽器網址：`http://localhost:8502`
- **功能特點**：
  - 專門受理電腦周邊三大品類（⌨️ 鍵盤、🖱️ 滑鼠、🎧 耳機）瑕疵退換貨申請。
  - 支援填寫訂單編號、買家 Email、故障原因及上傳瑕疵實體照片。
  - **進度查詢與照片補傳**：買家可輸入訂單編號或 Email 查詢審核狀態；若店長標記為「需補件」，可直接在此查看補件要求並上傳補充照片。
  - **安全防護**：完全隔絕後台審核台、風控評分、BI 數據與系統設定，保障商家商務機密。

---

### 2. 啟動【商家端管理後台】(Merchant / Admin Desk)
另開一個終端機，輸入：
```bash
streamlit run app.py --server.port 8501
```
- 瀏覽器網址：`http://localhost:8501`
- **功能特點**：
  1. **🧑‍💼 店長：人機對照審核台 (HITL)**：
     - 紅黃綠燈風險分流（🟢 低險快審 / 🟡 需補件 / 🔴 高風險駁回）。
     - 點擊「⚠️ 要求補件」**彈出專屬小視窗**，勾選缺失項目（缺照片、操作短片、檢測截圖等）並填寫指示，確認後更新案件並由 `zhuant610@gmail.com` 發送通知信。
  2. **📊 老闆：BI 營運成效儀表板**：
     - 核心商業指標、退貨品類分佈圖表、爭議防詐省下之逆物流成本與工時效益。
  3. **⚙️ 系統設定 & API**：
     - Gmail SMTP 應用程式密碼設定（持久化儲存於 `email_config.json`，刷新不遺失）。
     - 一鍵發送測試信件驗收工具。
     - 資料庫還原展示按鈕。

## 🛠️ 技術架構
- **開發語言**：Python 3.13
- **前端介面與路由**：Streamlit 1.45 (前後台獨立雙程式架構：`buyer.py` + `app.py`)
- **本地資料庫**：SQLite 3 (`disputes.db` 即時雙向連線)
- **郵件通知服務**：Python `smtplib` (寄件信箱: `zhuant610@gmail.com`，使用 Gmail 16 碼 App Password 授權發信)
- **圖表分析**：Pandas, Streamlit Native Visualizations
- **多模態 AI**：電腦周邊專用模擬風控引擎 / Google Gemini 2.5 Flash
